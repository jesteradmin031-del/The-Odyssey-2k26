# 📤 Odyssey Hackathon — Project Submission Guide

All participants must follow the instructions below when uploading their project files to the Odyssey GitHub repository.

## 💻 Method 1: GitHub Desktop

1. Install [GitHub Desktop](https://desktop.github.com/).
2. Sign in with your GitHub account.
3. Clone the Odyssey repository to your computer.
4. Copy your project files into your team's designated folder.
5. Open GitHub Desktop and review the changed files.
6. Enter a meaningful commit message, such as `Submit Team Project`.
7. Click **Commit to main** or commit to the designated branch.
8. Click **Push origin** to upload your changes.

## 🖥️ Method 2: Git Bash / Terminal

1. Install [Git](https://git-scm.com/downloads).
2. Clone the repository:

   ```bash
   git clone <repository-url>
   cd <repository-name>
   ```

3. Add your project files to the designated folder.
4. Check the changed files:

   ```bash
   git status
   ```

5. Stage only your team's files:

   ```bash
   git add <your-designated-folder>
   ```

6. Commit and push your changes:

   ```bash
   git commit -m "Submit hackathon project"
   git push origin main
   ```

**Note:** Replace the placeholders with the correct repository URL, folder path, and branch name. Use the branch specified by the organizers.

## 📱 Method 3: Mobile Devices

1. Open the official [GitHub mobile app](https://github.com/mobile) or visit [GitHub](https://github.com/) in your mobile browser.
2. Sign in to your GitHub account.
3. Open the Odyssey repository and navigate to your designated folder.
4. If file uploads are supported through your browser, use the upload option to select your project files.
5. Review the selected files and commit the changes with a meaningful message.

**Important:** Mobile upload options may be limited. For uploading multiple files or complete project folders, using GitHub Desktop or Git Bash on a computer is recommended.

## ⚠️ Mandatory Rules & Regulations

- **Submit Only Your Own Work:** Upload only your team's project files to the assigned folder.
- **Respect Other Teams:** Never modify, delete, overwrite, or interfere with another team's files.
- **Follow Organizer Instructions:** Use the specified repository, folder, and branch.
- **Verify Before Committing:** Review all changed files before committing or pushing.
- **Protect Sensitive Information:** Never upload passwords, API keys, access tokens, or private credentials.
- **Avoid Unnecessary Files:** Do not upload `node_modules`, temporary files, build artifacts, or unrelated content unless explicitly required.
- **Maintain Documentation:** Include a `README.md` describing your project, technologies, and setup instructions.
- **No Unauthorized Repository Changes:** Do not force-push, alter repository settings, or change shared configurations without permission.
- **Resolve Permission Issues Properly:** Contact the organizers if you cannot access or upload to the repository. Never attempt to bypass access restrictions.
- **Meet Submission Deadlines:** All project files must be submitted within the deadline announced by the organizers.

## ✅ Final Checklist

Before submitting, confirm that:

- [ ] Your files are in the correct team folder.
- [ ] Only your team's files are included in the commit.
- [ ] No secrets or sensitive information are exposed.
- [ ] Your project documentation is included.
- [ ] Your changes have been successfully pushed or uploaded.
- [ ] You have followed all official hackathon instructions.
